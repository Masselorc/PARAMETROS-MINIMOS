# Parâmetros Mínimos - Ouvidoria SENAPPEN

Repositório destinado ao monitoramento, análise e consolidação dos dados de **Parâmetros Mínimos das Ouvidorias** (SENAPPEN / Ministério da Justiça e Segurança Pública).

## 📊 Estrutura de Dados

O projeto conta com a base de dados em planilha (`DADOS.xlsx`) contemplando as dimensões:

- **00_Metodologia**: Diretrizes metodológicas e critérios adotados.
- **01_Institucionalização**: Nível e consolidação institucional das unidades.
- **02_Autonomia**: Autonomia operacional e decisória.
- **03_Imparcialidade**: Garantias e práticas de imparcialidade.
- **04_Acessibilidade**: Canais de acesso e atendimento ao cidadão/custodiado.
- **05_Transparência**: Relatórios públicos e divulgação de informações.
- **06_Integração Tec**: Integração com sistemas e bases tecnológicas.
- **07_Maturidade**: Diagnóstico do nível de maturidade.
- **08_Resumo**: Síntese e consolidação dos resultados.
